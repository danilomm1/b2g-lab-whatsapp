# Integrações

Um arquivo por canal (ex.: `meta.md`, `whatsapp.md`, `youtube.md`). Ao concluir cada fase do roadmap, atualize o arquivo do canal com as seções abaixo.

## Modelo

```markdown
# <Canal>

**Versão da API:** <ex.: Graph API v24.0> (também registrada em settings)
**Última revisão:** <data>

## O que funcionou
## Limitações encontradas
## Permissões necessárias (e status no App Review)
## Custos observados
## Próximos passos
```
